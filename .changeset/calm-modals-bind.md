**core/tokens/modal**: Style modal through own Component tokens for text color, backdrop color, viewport margin, title close-button clearance and actions gap (`--ds-modal-color-text`, `--ds-modal-backdrop-color-background`, `--ds-modal-margin`, `--ds-modal-title-padding-end`, `--ds-modal-actions-gap`), and add Alias token `--ds-alias-space-gap-2xl`. `modal-width` no longer defaults to `640`, so `--ds-modal-width` / `--modal-width` now apply when the property is not set. Modal text color is now explicitly `--ds-alias-text-color-primary` instead of inherited.
