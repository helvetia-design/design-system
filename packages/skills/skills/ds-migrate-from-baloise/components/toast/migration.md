# toast

Migrate every `bal-toast` usage to `ds-toast`. Init has already added the `@helvetia-design/*` packages. This task rewrites usages only.

The legacy folder has no child elements. Rewrite `bal-toast` only. Leave slotted content in place. `bal-close` is drawn inside the legacy toast and is not a consumer tag. `bal-toaster` and `BalToaster` are not this component and stay unchanged. `bal-notices` follows the Notices container section.

### Tags and imports

- **HTML**: `<bal-toast>` becomes `<ds-toast>`, including the closing tag.
- **Angular**: `<bal-toast>` becomes `<ds-toast>` in `.html` templates and in inline `template:` strings, including the closing tag. When a file imports `BalToast` from `@baloise/ds-angular`, move only `BalToast` to `import { DsToast } from '@helvetia-design/angular'` and leave the other symbols on the `@baloise` import.
- **React**: `<BalToast>` becomes `<DsToast>` and `</BalToast>` becomes `</DsToast>`. Import `DsToast` from `@helvetia-design/react`. When the existing `@baloise/ds-react` import also binds other symbols, move only `BalToast` to `import { DsToast } from '@helvetia-design/react'` and leave the other symbols on the `@baloise` import. The generated `DsToast` wrapper is deprecated. JSX still rewrites to `DsToast`. Do not rewrite JSX into the `useToast` hook. That hook replaces imperative `balToastController` calls only, which the controller rows below cover.

### React before and after

A toast opened in a `useEffect` and closed in its cleanup, before:

```tsx
import { balToastController } from '@baloise/ds-core'

useEffect(() => {
  const toast = balToastController.create({ message: 'Gespeichert.', color: 'success' })
  return () => {
    void toast?.close?.()
  }
}, [])
```

After:

```tsx
import { useToast } from '@helvetia-design/react'

const [presentToast, dismissToast] = useToast()

useEffect(() => {
  void presentToast({
    heading: '',
    message: 'Gespeichert.',
    color: 'success',
    closable: true,
    duration: 0,
    closeHandler: () => undefined,
    actionHandler: () => undefined,
  })
  return () => {
    void dismissToast()
  }
}, [])
```

`useToast` comes from `@helvetia-design/react`, and `balToastController` leaves the `@baloise/ds-core` import. `heading: ''` is added because `Alert.heading` is required and legacy had none. `closable: true` and `duration: 0` keep the legacy defaults. `closeHandler` and `actionHandler` are added because `Alert` requires them. The element variable is gone, and `.close()` becomes `dismissToast()`. Report the cleanup.
